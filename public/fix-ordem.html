🔢 Corrigir Ordem (seq) a partir do Excel

O que isto faz: reescreve o campo seq dos movimentos para coincidir com a ordem cronológica do Excel. Útil quando movimentos no mesmo dia aparecem fora de ordem na app.

Apenas processa movimentos com data ≥ data mínima. Os anteriores mantêm-se intactos.

Faz match exato (data + descrição + valor); se não bater, tenta data + valor único. Reordena fazendo seq = 1, 2, 3, ... dentro do intervalo. Movimentos mais antigos ficam com seq negativo para não conflitar.

Fluxo: arrasta o Excel → corre Dry-run → revê → carrega Aplicar.
