🏢 Importar Entidades

Carrega a lista de fornecedores, clientes e empresas para a base de dados de Entidades.

Podes escolher o teu .xlsx (colunas Tipo, Nome / Designação, Nome Fantasia, NIF, Email, Telefone, IBAN, Morada, Categoria) ou usar a cópia que veio com o site.

Não duplica. Antes de inserir compara com o que já existe, pelo NIF quando há, senão pelo nome. Podes correr mais do que uma vez.
Antes: a coluna do nome comercial tem de existir. No SQL Editor do Supabase:

alter table entidades add column if not exists nome_fantasia text;
alter table entidades add column if not exists categoria text;
