🔧 Corrigir Saldos a partir do Excel

O que isto faz: recebe o Excel mestre (com saldos corretos por movimento) e compara, para cada aba, com os movimentos no Supabase. Faz match usando a chave data + descrição + valor. Atualiza apenas o campo saldo — nada mais é tocado.

Apenas processa movimentos com data ≥ data mínima (ajusta abaixo). Os anteriores são ignorados.

Fluxo: arrasta o ficheiro → corre Dry-run → revê o relatório → carrega Aplicar apenas se tudo bater certo.
