💾 Backup Completo da Base de Dados

Descarrega tudo o que existe nas tabelas principais do Supabase como um único ficheiro JSON com timestamp. Útil como ponto de restauro antes de operações destrutivas, ou só para arquivo.

Tabelas incluídas: movimentos, faturas, pagamentos_extras, vendas, fracoes, entidades, contas, orcamento, profiles.
Não inclui: dados do auth (utilizadores/passwords) — esses ficam só no Supabase Auth.
