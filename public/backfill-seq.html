🔢 Backfill SEQ — Movimentos sem ordem

O que isto faz: percorre todos os movimentos no Supabase que têm seq IS NULL (vieram da migração inicial sem ordem) e atribui-lhes um valor de seq baseado na posição original no caixa_unico_v2.json (que é a ordem do Excel original: linha 0 = mais recente).

Resultado: a tabela Extrato passa a mostrar os movimentos pela ordem certa, com os imports recentes sempre no topo. Corre uma vez. É idempotente — se voltar a correr, só preenche o que ainda estiver NULL.
