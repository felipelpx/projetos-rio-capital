📡 Verificar e Ativar Realtime

O Fluxo Futuro, Pagamentos, Extratos e Faturas só atualizam automaticamente entre utilizadores se a tabela tiver Realtime ativado no Supabase.

Esta página verifica se cada tabela está bem configurada e, se não estiver, dá-te o SQL para a ativar.

1. Verificar estado atual

2. SQL para ativar Realtime (correr no Supabase SQL Editor)

-- Adicionar todas as tabelas ao publication "supabase_realtime"
-- (idempotente: se já estiver na publication, não dá erro)

-- Movimentos (extratos bancários)
ALTER PUBLICATION supabase_realtime ADD TABLE movimentos;

-- Faturas (Contas a Pagar)
ALTER PUBLICATION supabase_realtime ADD TABLE faturas;

-- Pagamentos manuais (Fluxo Futuro)
ALTER PUBLICATION supabase_realtime ADD TABLE pagamentos_extras;

-- Vendas (Comercial)
ALTER PUBLICATION supabase_realtime ADD TABLE vendas;

-- Frações
ALTER PUBLICATION supabase_realtime ADD TABLE fracoes;

-- Mapas de pagamento
ALTER PUBLICATION supabase_realtime ADD TABLE mapas_pagamento;
ALTER PUBLICATION supabase_realtime ADD TABLE mapas_pagamento_itens;

-- Contas (saldos)
ALTER PUBLICATION supabase_realtime ADD TABLE contas;

-- Orçamento
ALTER PUBLICATION supabase_realtime ADD TABLE orcamento;

-- Entidades
ALTER PUBLICATION supabase_realtime ADD TABLE entidades;

-- Verificar
SELECT schemaname, tablename FROM pg_publication_tables WHERE pubname = 'supabase_realtime';

3. Resposta esperada após correr o SQL

O SELECT final deve mostrar pelo menos estas 10 tabelas. Se aparecerem todas, o realtime está pronto.
