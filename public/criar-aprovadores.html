SQL alternativo (se preferires)

Se quiseres correr manualmente no SQL Editor depois de criar os utilizadores no dashboard:

-- Configurar Marcelo, Henrique e Marcia como admin + aprovação nível 2
UPDATE profiles
SET role = 'admin',
    approval_level = 2,
    can_create_mapas = true
WHERE id IN (
  SELECT id FROM auth.users
  WHERE email IN ('marcelo@riocapital.pt', 'henrique@riocapital.pt', 'marcia@riocapital.pt')
);

-- Verificar
SELECT p.email, p.role, p.approval_level, p.can_create_mapas
FROM profiles p
ORDER BY p.email;
