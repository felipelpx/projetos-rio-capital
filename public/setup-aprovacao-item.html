✓ Setup — aprovar cada pagamento individualmente

Para se poder aprovar ou recusar cada pagamento do mapa por si, a tabela mapas_pagamento_itens precisa de guardar a decisão de cada linha: quem aprovou, em que nível e quando. Corre o SQL abaixo uma única vez.

1Abre o SQL Editor do Supabase

Vai a Supabase SQL Editor e cola o SQL abaixo.

2Corre o SQL

-- Decisão de cada item do mapa, por nível de aprovação
alter table mapas_pagamento_itens
  add column if not exists aprovado_n1     boolean not null default false,
  add column if not exists aprovado_n1_por uuid,
  add column if not exists aprovado_n1_em  timestamptz,
  add column if not exists aprovado_n2     boolean not null default false,
  add column if not exists aprovado_n2_por uuid,
  add column if not exists aprovado_n2_em  timestamptz,
  add column if not exists recusado        boolean not null default false,
  add column if not exists recusado_por    uuid,
  add column if not exists recusado_em     timestamptz;

create index if not exists idx_mpi_decisao on mapas_pagamento_itens(mapa_id, recusado);

-- Mapas já aprovados ficam com todos os itens marcados como aprovados, para o
-- histórico não aparecer como "por decidir".
update mapas_pagamento_itens i
   set aprovado_n1 = true, aprovado_n2 = true
  from mapas_pagamento m
 where i.mapa_id = m.id
   and m.status = 'aprovado'
   and (i.aprovado_n1 = false or i.aprovado_n2 = false);

-- Mapas já em Pendente N2 têm o nível 1 dado como aprovado.
update mapas_pagamento_itens i
   set aprovado_n1 = true
  from mapas_pagamento m
 where i.mapa_id = m.id
   and m.status = 'pendente_nivel_2'
   and i.aprovado_n1 = false;

notify pgrst, 'reload schema';

3Confirma

Abre o ERP → Pagamentos → um mapa por aprovar. Cada linha passa a ter os botões ✓ e ✕ na coluna Decisão, e o botão de fechar o nível só fica ativo quando não sobrar nenhum por decidir.

As duas instruções update no fim são para o histórico: sem elas, os mapas que já estavam aprovados apareceriam com todos os itens "por decidir". Correr o SQL outra vez não faz mal.
