🔎 Check Saldos — Verificação de coerência

Para cada movimento, calcula saldo_anterior + valor_atual − saldo_atual.
Se = 0 → coerente. Se ≠ 0 → há erro nesta linha (no valor ou no saldo).

Apenas valida movimentos com data ≥ 01/01/2025. O saldo_anterior usado para o primeiro movimento dentro do intervalo é o saldo do último movimento antes de 2025 (a âncora).

Este check é não-destrutivo — apenas lê dados e mostra inconsistências.
