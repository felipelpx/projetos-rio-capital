⚙️ Setup — coluna status em pagamentos_extras

Para que se possa marcar pagamentos do Fluxo Futuro como Pagos, a tabela pagamentos_extras precisa de uma coluna status. Esta página verifica se já existe e dá-te o SQL a correr se não existir.

1Abre o SQL Editor do Supabase

Vai a Supabase SQL Editor e cola o SQL abaixo.

2Corre o SQL

-- Adiciona coluna status com valor default 'Pendente'
ALTER TABLE pagamentos_extras
  ADD COLUMN IF NOT EXISTS status text NOT NULL DEFAULT 'Pendente';

-- Marca tudo o que existir como 'Pendente'
UPDATE pagamentos_extras SET status = 'Pendente' WHERE status IS NULL;

-- Index opcional para consultas rápidas por status
CREATE INDEX IF NOT EXISTS idx_pagamentos_extras_status ON pagamentos_extras(status);

3(opcional) Verifica novamente

Carrega outra vez no botão acima para confirmar que a coluna ficou criada.

4Já está

Volta à app, vai ao Fluxo Futuro, expande ⚠️ Vencidas. Cada pagamento Manual passa a ter um botão ✓ Marcar Pago. Quando carregares, sai do bucket de vencidas e o caixa líquido recupera o valor.
